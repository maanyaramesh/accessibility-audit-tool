Accessibility Audit Tool — AI-Powered Website Accessibility Analyzer

📋 Overview

Accessibility Audit Tool is a full-stack web accessibility testing platform that analyzes websites using automated accessibility auditing techniques powered by Lighthouse, Puppeteer, and Axe principles.

The project allows users to enter any website URL and receive a detailed accessibility report including scores, issue detection, performance insights, and accessibility improvement recommendations.

The system demonstrates full-stack engineering, browser automation, accessibility testing workflows, API communication, and deployment architecture using modern JavaScript technologies.

⚡ Installation

Clone Repository

git clone https://github.com/maanyaramesh/accessibility-audit-tool.git
cd accessibility-audit-tool

⸻

📦 Install Frontend Dependencies

cd client
npm install

⸻

📦 Install Backend Dependencies

cd ../server
npm install

⸻

🚀 Running the Project

Step 1 — Start Backend Server

cd server
npm run dev

Backend runs at:

http://localhost:3001

⸻

Step 2 — Start Frontend

Open another terminal:

cd client
npm run dev

Frontend runs at:

http://localhost:5173

User Enters Website URL
